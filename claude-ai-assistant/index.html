방법 1

Cowork Dispatch

2026년 3월 17일 출시. 폰에서 문자 보내듯이 Claude에게 일을 시키면, 내 맥에서 알아서 처리합니다.

💡 한마디로
폰 = 리모컨, 맥 = 일꾼. 파일, 플러그인, 커넥터 전부 맥에서 로컬로 실행됩니다.
1

앱 준비

  • Claude Pro ($20/월) 또는 Max ($100/월) 구독
  • Claude Desktop 앱 최신 버전 (macOS / Windows)
  • Claude 모바일 앱 최신 버전 (iOS / Android)
2

Dispatch 연결 (2분)

  1. 맥 또는 폰의 Claude 앱에서 왼쪽 패널의 Dispatch 클릭
  2. Get started 선택
  3. 파일 접근 권한, 화면 꺼짐 방지 설정 확인
  4. Finish setup 클릭

끝. QR 코드 스캔하면 연결됩니다.

3

써보기

폰에서 메시지 보내보세요:

Downloads 폴더에 있는 PDF들 내용 요약해서 정리해줘

맥이 알아서 PDF 읽고 → 정리하고 → 결과를 보여줍니다.

4

역할별로 쓰는 법

Dispatch에는 채널이 없으니까, 메시지에 역할을 명시하면 됩니다:

[마케팅] 이번 주 인스타 캡션 3개 초안 써줘

[개발] 이 에러 로그 분석해줘. ~/logs/error.log 파일 봐봐

[리서치] 한국 이커머스 시장 최근 트렌드 정리해줘
5

더 체계적으로: CLAUDE.md

프로젝트 폴더에 CLAUDE.md를 만들어놓으면, Dispatch에서도 그 규칙을 따릅니다:

# 내 AI 비서 규칙

## 기본 행동
- 한국어로 응답
- 간결하게, 불필요한 서론 없이
- 결과물은 ~/Documents/outputs/ 에 저장

## [마케팅] 모드
- SNS 트렌드 반영
- 타겟 오디언스 고려

## [개발] 모드
- 코드 예시 포함
- 보안/성능 고려

## [리서치] 모드
- 출처 명시
- 데이터 기반
⚠️ Dispatch 주의사항
  1. 맥이 켜져 있어야 합니다. 잠자기 모드면 멈춤.
  2. 리서치 프리뷰 단계. 복잡한 건 50:50. 간단한 것부터.
  3. 대화 스레드 1개. 병렬 태스크 불가.
  4. 완료 알림 없음. 직접 확인 필요.
  5. 보안 주의. 파일 삭제/이동도 실행 가능. 권한 설정 꼼꼼히.
방법 2

Discord 채널 라우팅

봇 1개를 Discord 서버에 연결하고, 채널 이름에 따라 자동으로 역할이 바뀌는 시스템.

Discord 서버
├── #마케팅  →  마케팅 전문가로 응답
├── #개발    →  시니어 개발자로 응답
├── #리서치  →  리서처로 응답
└── #일반    →  범용 어시스턴트
🚫 왜 봇 1개인가? (삽질 방지)

"채널마다 봇을 따로 만들면?" → 안 됩니다.

Discord 플러그인은 토큰을 ~/.claude/channels/discord/.env 하나에 저장합니다. 여러 봇을 띄워도 마지막 봇만 온라인. HOME 분리, 순차 실행, 심링크 등 전부 실패합니다.

봇 1개 + CLAUDE.md 채널 라우팅 = 유일한 해결책.

1

Discord 봇 만들기 (5분)

  1. discord.com/developers/applications 접속
  2. New Application → 이름 입력
  3. Bot 탭 → Reset Token → 토큰 복사 (비밀번호 취급!)
  4. Privileged Gateway Intents 3개 전부 ON:
✅ Presence Intent
✅ Server Members Intent
✅ Message Content Intent    ← 이거 까먹으면 봇이 메시지를 못 읽음!
  1. OAuth2 → URL Generator → Scopes: bot → Permissions: Send Messages, Read Message History, View Channels
  2. 생성된 URL로 서버에 초대
2

CLAUDE.md 작성 (10분) — 핵심!

이 파일이 봇의 두뇌입니다. 템플릿을 복사해서 수정하세요:

# 내 Discord AI 비서
> 채널 이름에 따라 역할이 전환된다.

## 채널 라우팅

| 채널       | 역할              | 설명                     |
|-----------|-------------------|--------------------------|
| #마케팅   | 마케팅 전문가       | 콘텐츠 전략, SNS, 카피     |
| #개발     | 시니어 개발자       | 코드 리뷰, 아키텍처        |
| #리서치   | 리서치 어시스턴트   | 시장 조사, 데이터 분석      |
| #일반     | 범용 어시스턴트     | 기본 모드                  |

---
## 📢 #마케팅
너는 마케팅 전문가다.
- SNS 트렌드 반영
- 타겟 오디언스 고려
- 구체적 액션 아이템

## 💻 #개발
너는 시니어 풀스택 개발자다.
- 코드 예시 포함
- 보안/성능 고려

## 🔍 #리서치
너는 리서치 어시스턴트다.
- 출처 명시
- 데이터 기반 분석
3

토큰 등록 + 실행 (2분)

# 프로젝트 폴더로 이동
cd ~/my-discord-bot

# Claude Code 실행 후 토큰 등록
claude
/discord:configure 여기에_토큰_붙여넣기

# 채널 모드 실행
claude --channels plugin:discord@claude-plugins-official

Listening... 뜨면 성공!

4

페어링 (1분)

  1. Discord에서 봇에게 DM 보내기
  2. 봇이 6자리 코드 줌
  3. Claude Code 터미널에서:
/discord:access pair 123456
5

채널 만들고 테스트

Discord 서버에 CLAUDE.md에 쓴 채널들 생성 → 봇에게 말 걸기. 끝!

💡 백그라운드 실행 (tmux)

터미널 닫아도 봇이 계속 돌게 하려면:

#!/bin/bash — start.sh
BASE="$HOME/my-discord-bot"

tmux kill-session -t mybot 2>/dev/null
pkill -f "claude --channels" 2>/dev/null
sleep 2

tmux new-session -d -s mybot \
  "cd '$BASE' && claude --channels plugin:discord@claude-plugins-official"

echo "✅ 실행 완료"
echo "접속: tmux attach -t mybot"
echo "종료: tmux kill-session -t mybot"
고급 팁

두 방법 모두에 적용

📁 데이터 폴더 연결

CLAUDE.md에서 특정 폴더를 참조하게 할 수 있습니다:

## 📢 #마케팅
### 데이터
- ~/my-bot/data/마케팅/캠페인/  ← 진행 중인 캠페인
- ~/my-bot/data/마케팅/레퍼런스/ ← 벤치마크 자료

해당 채널에서 질문하면 폴더 내 파일을 참조해서 답변합니다.

👤 공유 프로필

여러 역할에서 공통으로 쓸 정보는 별도 파일로:

my-bot/
├── CLAUDE.md
└── shared/
    └── company-profile.md   ← 회사 정보, 브랜드 가이드

CLAUDE.md에서 shared/company-profile.md 참조라고 쓰면 됩니다.

➕ 채널/역할 추가

새 역할 추가 = 딱 2가지:

  1. Discord에 채널 생성 (또는 Dispatch면 새 태그 정하기)
  2. CLAUDE.md에 라우팅 테이블 + 섹션 추가

봇 재시작하면 바로 적용.

TROUBLESHOOTING

트러블슈팅 (Discord)

봇이 Discord에서 오프라인이에요

90%는 토큰 문제. 직접 테스트:

cd ~/.claude/plugins/cache/claude-plugins-official/discord/0.0.1
bun run start

gateway connected → 정상 | TokenInvalid → 토큰 재발급

봇이 메시지를 못 읽어요
Developer Portal → Bot 탭 → Message Content Intent 켜져 있는지 확인. 가장 자주 까먹는 부분입니다.
"Channels are not currently available" 에러
Claude Code 업데이트: claude update
좀비 프로세스가 남아요
pkill -9 -f "claude --channels"
pkill -9 bun
